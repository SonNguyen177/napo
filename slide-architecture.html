NAPO Matching Engine — Kiến trúc tổng quan

3 process · In-memory only · No DB · No queue · No cache — Hackathon demo

Vai trò từng component

1 Admin UI :3001
  • React 19 + Vite · không dùng state library ngoài
  • useAdminApi — wrapper REST để ra lệnh
  • useAdminWebSocket — nhận snapshot 0.5s
  • Panel: MarketControl · StockConfig
  • Panel: OrderBookView · TradeHistory
  • Panel: CommLogs · ClientCount
2 Client UI :5173
  • React 19 + Vite + recharts
  • 1 WS duy nhất tới :8765 — không REST
  • auto-reconnect 2s
  • Gửi: new_order (LIMIT/MARKET) · subscribe
  • Nhận exec report riêng; trade + update broadcast
  • Cap: trades ≤ 200 · execReports ≤ 100
3 ws_server.py
  • ExchangeWSServer · Port :8765
  • Nhận JSON new_order / subscribe
  • execution_report → unicast tới client đặt lệnh
  • trade + market_update → _broadcast_json_all
  • On connect → gửi market_snapshot per symbol
4 api.py (FastAPI)
  • REST /api/market/start|stop|state
  • REST /api/stocks + PUT /api/stocks/{symbol}
  • REST /api/trades · /api/logs · /api/clients
  • WS /ws/admin push admin_state mỗi 0.5s
  • Server → Admin one-way (không đọc msg từ admin)
5 matching.py
  • MatchingEngine singleton — 1 instance duy nhất
  • Kiểm tra is_open() trước mỗi lệnh
  • Route order tới đúng OrderBook[symbol]
  • _trades: nguồn sự thật lịch sử giao dịch
  • price < 0 hoặc qty ≤ 0 → os._exit(1)
6 order_book.py
  • 1 instance per symbol (ACB / FPT / VCK)
  • validate_order(): floor/ceiling/price_step/qty_step
  • process_order(): price-time priority
  • Bids/Asks: dict[int_price, deque[Order]]
  • Trả MatchResult(trades, exec_reports, updates)
  • Config là reference → admin edits tức thì

Luồng đặt lệnh (happy path)

Client UI │ {type:"new_order", symbol:"ACB", side:"BUY", price:20100, qty:100} ▼ ws_server.py (_handle_new_order) │ symbol.upper() → submit_order(order) ▼ matching.py (MatchingEngine.submit_order) │ check is_open() → route tới OrderBook["ACB"] ▼ order_book.py (validate_order → process_order) │ fill nếu có lệnh đối ứng → MatchResult ▼ ws_server.py (xử lý kết quả) ├─► execution_report → chỉ client đặt lệnh ├─► trade → broadcast tất cả client └─► market_update → broadcast tất cả client │ api.py (0.5s sau) │ snapshot admin_state ▼ Admin UI cập nhật
⚠️  Chỉ có 1 process engine giữ toàn bộ state trong RAM.  Restart = mất hết.  Không DB · Không queue · Không cache — thiết kế cố ý cho hackathon demo.
