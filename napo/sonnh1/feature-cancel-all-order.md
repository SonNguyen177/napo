# Tính năng huỷ tất cả lệnh

## Mô tả tính năng :
 *Yêu cầu* : 
- Thêm tính năng cho phép huỷ toàn bộ lệnh đang trong queue, order book. Chức năng huỷ tất cả lệnh chờ khớp, tất cả các mã trên hệ thống
 *Phạm vi* :
 - Chỉ huỷ các lệnh ở trạng thái chờ khớp, nếu đã khớp một phần thì huỷ phần còn lại
 - Huỷ trên tất cả các mã có trong hệ thống
 *Hệ thống* :
 - Dùng trên admin page
