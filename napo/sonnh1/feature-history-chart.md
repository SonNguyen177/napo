# Tính năng xem chart giao dịch

## Mô tả tính năng :
 *Yêu cầu* : 
- Chỉnh sửa tính năng vẽ chart thống kê lịch sử khớp lệnh trên web client
 *Phạm vi* :
 - Chart cho phép lựa chọn view dạng nến (HLOC) và dạng line
 - Chart gồm các trục thời gian chiều ngang, khối lượng và giá khớp chiều dọc
 - Hiển thị dựa theo lịch sử khớp lệnh, vẽ realtime

 *Hệ thống* :
 - Dùng trên client page

 *Giao diện* :
 - Giao diện dễ nhìn, thân quen, ưu tiên theo style của tradingview
