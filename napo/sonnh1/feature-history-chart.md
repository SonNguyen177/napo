# Tính năng xem chart giao dịch

## Mô tả tính năng :
 *Yêu cầu* : 
- Thêm tính năng vẽ chart thống kê lịch sử khớp lệnh trên web client
 *Phạm vi* :
 - Chart cho phép view dạng nến (HLOC) và dạng line
 - Chart gồm các trục thời gian khoảng từ 8 đến 15h, khối lượng và giá khớp
 - Với chart Line, có option xem 1 mã hoặc nhiều mã cùng lúc trên trên chart

 *Hệ thống* :
 - Dùng trên client page

 *Giao diện* :
 - Giao diện dễ nhìn, thân quen, ưu tiên theo style của tradingview
